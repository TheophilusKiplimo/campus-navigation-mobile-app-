# User Journey

## User Persona

Brian Kiptoo – First-Year Student

## Goal

Locate the Computer Science Lecture Hall before the first class.

| Stage | User Action | User Feeling | System Response | Improvement Opportunity |
|--------|-------------|--------------|-----------------|-------------------------|
| Discover Need | Brian realizes he doesn't know where the lecture hall is. | Confused | Opens the Campus Navigator app. | Provide a simple home screen. |
| Search | Searches for "Computer Science Lecture Hall". | Hopeful | Displays matching results instantly. | Offer search suggestions. |
| Select | Selects the correct lecture hall. | Confident | Displays building information and directions. | Show estimated walking time. |
| Navigate | Follows the directions. | Comfortable | Updates navigation progress. | Highlight landmarks along the route. |
| Arrive | Reaches the lecture hall successfully. | Satisfied | Displays arrival confirmation. | Allow users to save the location as a favourite. |

## User Journey Summary

The application reduces confusion by providing a straightforward process for searching, locating, and navigating to campus facilities.
