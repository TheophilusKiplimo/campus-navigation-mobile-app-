# Functional Requirements

The Campus Navigator Mobile Application shall provide the following functions:

## User Authentication

- User login
- User registration
- Logout

---

## Navigation Features

- Search for campus buildings.
- Search for university offices.
- Locate lecture halls.
- Locate laboratories.
- Find university services.

---

## Location Information

- Display building details.
- Display navigation directions.
- Show nearby facilities.

---

## Saved Locations

- Save favourite places.
- View saved locations.
- Remove saved locations.

---

## User Profile

- View profile.
- Edit profile.
- Update contact information.

---

## Notifications

- Display important campus navigation alerts.
- Notify users about saved locations.
