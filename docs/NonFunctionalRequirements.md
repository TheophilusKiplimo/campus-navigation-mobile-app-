# Non-Functional Requirements

## Usability

The application should be simple, intuitive, and easy to use for students, staff, and visitors.

---

## Performance

Search results should be displayed within a few seconds.

---

## Accessibility

The interface should use readable fonts, high-contrast colors, and large touch targets suitable for mobile devices.

---

## Reliability

The application should consistently display accurate campus location information.

---

## Security

User account information should be protected through secure authentication.

---

## Compatibility

The prototype is designed for Android and iOS smartphones.

---

## Maintainability

The application should be easy to update as new campus buildings and services become available.
