# Campus Navigator Wireframes

## Overview

This folder contains the low-fidelity wireframes for the Campus Navigator mobile application prototype developed using Balsamiq.

## Purpose

The wireframes demonstrate the application's navigation flow and user interface based on Human-Computer Interaction (HCI) principles.

## Main Screens

- Splash Screen
- Welcome Screen
- Login
- Registration
- Home Dashboard
- Search Results
- Location Details
- Navigation
- Password Reset
- Profile
- Menu
- Settings
- Saved Locations
- History

## HCI Principles Applied

- Consistency
- Simplicity
- Visibility of system status
- Recognition rather than recall
- User control and freedom
- Error prevention
- Clear navigation

## Prototype

The prototype demonstrates common user tasks such as searching for campus buildings, viewing directions, saving locations, and managing user settings.
