# Usability Test Plan

## Objective

Evaluate the usability of the Campus Navigator prototype.

## Participants

- Student 1
- Student 2
- Student 3
- Lecturer
- Visitor

## Tasks

1. Find the Main Library.
2. Locate the Finance Office.
3. Search for a lecture hall.
4. Save a favourite location.
5. Update the user profile.

## Metrics

- Task completion
- Time taken
- Number of errors
- User satisfaction
