# Final Project Report

## Project Summary

Campus Navigator is a mobile application prototype designed to help students, lecturers, staff, and visitors locate buildings, lecture halls, laboratories, and university services.

The project follows Human-Computer Interaction principles by focusing on usability, accessibility, consistency, and simple mobile navigation.

## Objectives Achieved

- Conducted user research.
- Developed user personas.
- Defined functional and non-functional requirements.
- Created user journeys and task flows.
- Designed a Balsamiq mobile prototype.
- Conducted usability testing.
- Improved the prototype based on user feedback.

## Conclusion

The prototype demonstrates how mobile technology can improve campus navigation through an intuitive and user-centered design.
